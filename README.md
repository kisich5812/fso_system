# FSO System

Репозиторий проектного предложения **FSO (Free Space Optics) System**.
Проект осуществляет двухсторонную передачу информации с помощью лазерного луча 
в условиях прямой видимости двух модулей связи.

## Содержание

- 3D модели деталей: см. [3d models](/3d%20models/)
- Исходный код программного обеспечения: см. [main](/main/) и [components](/components/)

## Установка и запуск ПО

**Пререквизиты**: установленное и активированное esp-idf программное окружение. 
Гайд на установку можете найти в [официальной докуменции](https://docs.espressif.com/projects/esp-idf/en/stable/esp32/get-started/)

Находясь в директории проекта, выполните следующие команды
```bash
idf.py set-target esp32-s3
idf.py build
```
После компиляции проекта, подключите esp32-s3 через USB кабель в ваш ПК и
выполните
```bash
idf.py flash
```

После чего программа будет загружена в esp. Для того, 
чтобы смотреть за выводом/вводом программы, выполните
```bash
idf.py monitor
```

Для выхода из `monitor`, нажмите `Ctrl+[`

## Использование программного обеспечения

После запуска программа просит ввести частоту, с которой будет передаваться 
сообщение. Если ввода не поступает или он не корректный, то программа выбирает
дефолтную частоту. После этого программа подает сообщение на модуль лазера в
виде битов, а также читает полученные значения с фотодиода.
